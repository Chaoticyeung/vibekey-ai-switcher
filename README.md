# Vibe Key 四应用语音控制

把优篮子 Vibe Key（AU05-X）的旋钮和三个按键，用来切换克劳德（Claude）、代码助手（Codex）、工作伙伴（WorkBuddy）、深度求索（DeepSeek），并通过听写工具（Typeless）输入语音。

## 准备

- macOS、[优篮子工作室（Ulanzi Studio）官方下载页](https://www.ulanzi.com/pages/ulanzi-app)提供的应用，以及已配对的 AU05-X。
- 已安装想要控制的应用，以及听写工具（Typeless）。听写快捷键设为**右 Option 键**。
- 苹果的 Swift 编译工具。若尚未安装，先运行 `xcode-select --install`。

程序会按应用的标识查找安装位置。没装齐四个应用也能安装；切到缺失的应用时会显示提示。

## 安装

在终端运行这一行：

```sh
git clone https://github.com/Chaoticyeung/vibekey-ai-switcher.git && cd vibekey-ai-switcher && sh install.command
```

也可以下载本仓库的压缩包，解压后双击 `install.command`。安装程序会找到当前选中的 AU05-X 预设、备份原文件、写入按键配置、编译控制程序，并设置登录后启动。若无法确认当前预设，会让你选择。安装时若退出了优篮子工作室，请在完成后手动重新打开它，以加载新预设。

首次安装会先询问是否创建**本机专用的代码签名证书**，并将私钥导入当前用户的默认钥匙串。证书仅设为代码签名用途；生成时的临时私钥文件会在导入后删除。每次更新时，钥匙串可能要求你确认使用私钥签名，但这不同于重新授予辅助功能权限。后续更新复用同一身份；如果身份不可用，安装会在修改设备预设和旧程序之前停止，不会悄悄换成临时签名。[苹果的代码签名说明](https://developer.apple.com/library/archive/technotes/tn2206/_index.html)解释了系统如何通过稳定的签名要求识别后续版本。

**首次安装后**，请到“系统设置 → 隐私与安全性 → 辅助功能”允许 `VibeKeyBridge`。若从旧的临时签名版本迁移到本机签名，需对新身份再授权一次；此后的更新应沿用该授权。macOS 要求授权由本人完成。控制程序不会自动打开系统设置。

## 按键

| 操作 | 功能 |
| --- | --- |
| 旋钮直接左转／右转 | 在四个应用间切换选择，屏幕短暂显示选中项 |
| 单按旋钮 | 打开选中的应用 |
| 快速连按两下旋钮 | 在选中的应用中新建对话／任务 |
| 上方小键 | 在当前应用开始／结束语音输入 |
| 中间对勾键 | 四个受支持应用中，唯一识别到授权对话框时确认；普通输入界面发送消息 |
| 下方叉号键 | 唯一识别到授权对话框时否决；普通输入界面发送退出／停止键 |
| 键盘快捷键 `⌃⌥⇧7` | 在当前选中的应用中新建对话／任务 |

应用顺序：克劳德（Claude）→ 代码助手（Codex）→ 工作伙伴（WorkBuddy）→ 深度求索（DeepSeek）。

语音键在**任何应用的当前输入框**使用听写工具（Typeless）：先点击输入框，再按语音键；它不会因为旋钮选中了另一应用而切换窗口。旋钮单按和新建对话仍作用于旋钮选中的应用。对勾键只在四个受支持应用中自动发送或处理授权；在其他应用中可以结束录音，但不会自动提交内容。

说完可按上方小键结束语音。在四个受支持应用中，也可直接按对勾键：程序最多等待 20 秒，确认文字进入输入框后再发送；若无法确认，会提示手动检查。在其他应用中，对勾键只结束录音，不会自动发送。

新建对话可以**快速连按两下旋钮**（两次间隔不超过约 0.4 秒），也可以按键盘快捷键 **Control＋Option＋Shift＋7**。程序会打开当前选中的应用，再使用该应用的“新建对话”入口。菜单栏的 Vibe Key 控制菜单也有同一入口。

授权按钮只会在焦点位于唯一可识别的授权对话框内时自动按下；出现多个候选或无法确认对话框时，会提示手动处理。四个应用的真实授权弹窗仍需逐一验证。

## 权限、安全与风险

- 授予**辅助功能**后，控制程序能够读取目标应用的界面文字、监听全局按键，并模拟按键或点击授权按钮。这是实现切换、语音输入和确认操作所必需的较高权限。程序只处理预设组合键，但无法证明按键一定来自 Vibe Key；普通键盘输入相同组合键也会触发。
- 语音键可以在任何应用中触发听写。使用前请确认光标所在位置，避免把语音文字输入到错误窗口或敏感字段。四个受支持应用以外，对勾键不会自动发送或确认。
- 本机签名证书及私钥属于你的登录钥匙串；任何能使用该私钥签名相同应用标识的程序都可能被系统视为本项目的后续版本。请保护钥匙串，不要导出或分享私钥。签名证书由本机自行生成，不代表苹果或优篮子的开发者认证。
- 为读取深度求索（DeepSeek）中可见但未暴露给系统的输入框，程序会为该应用启用增强辅助功能界面。这会让其界面内容可由已获辅助功能权限的程序读取。
- 安装程序会修改当前设备预设，并注册用户级登录启动项。它会先备份原配置，但安装中断或第三方应用更新仍可能导致配置失效。安装前请检查仓库源码；上面的一行命令获取的是执行时的最新主分支。
- 授权识别依赖目标应用提供的辅助功能界面。无法唯一确认授权对话框时会停止自动操作；即使识别成功，仍请在按对勾前看清授权内容。听写由第三方 Typeless 提供，本项目不控制其录音处理方式。
- 代码安全检查（Codex Security）在初版发现两项中等风险：预设页面路径可越界、授权按钮可能错配。本版增加了页面路径校验与唯一授权对话框限制。固定签名方案的差异检查还发现通用签名工具的私钥访问范围过宽，发布代码已移除相应白名单。扫描只覆盖当时的源码，不等于对 macOS 钥匙串、优篮子工作室或四个目标应用的安全认证。

**免责声明：**这是社区自定义配置，与优篮子或上述应用的开发商无关联。软件按现状提供；安装者应自行核对来源、备份和授权内容，并承担使用及第三方应用变化带来的风险。

## 故障排查

- 旋钮突然输入数字、语音键无反应：先确认控制程序正在运行。新版会尝试恢复失效的按键监听；如果仍无反应，退出并重新打开 `VibeKeyBridge`。
- 深度求索的输入框可见，却提示“未找到输入框”：新版会在使用前启用该应用的增强辅助功能界面。若仍出现提示，重新打开深度求索，再按语音键。
- 从旧临时签名版本迁移后，所有按键都失效：检查上述“辅助功能”授权。开关显示开启不一定代表新签名已获信任；后续使用同一签名身份更新时不应重复发生。

## 恢复原预设

每次安装前，原页面配置会保存到 `~/Library/Application Support/VibeKeyBridge/backups/`。退出优篮子工作室后，将相应备份复制回原预设页面的 `manifest.json`，再重新打开优篮子工作室。新安装的程序本体位于 `~/Applications/VibeKeyBridge.app`；若已有程序位于 `/Applications/VibeKeyBridge.app`，更新会沿用原位置。登录启动项位于 `~/Library/LaunchAgents/local.vibekey.bridge.plist`。

## 仓库内容

- `src/VibeKeyBridge.swift`：最终运行程序源码。
- `config/actions.json`：通用按键配置，不含设备编号或个人路径。
- `scripts/install.py`、`scripts/signing.py`、`install.command`：安装、签名与备份。
